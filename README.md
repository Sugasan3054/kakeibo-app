# 個人用家計簿 Web アプリ（kakeibo-app）

ブラウザ上で安全かつ軽快に動作する、個人向けのプログレッシブウェブアプリケーション（PWA）家計簿です。  
外部サーバーへデータを一切送信せず、全てのデータを端末のブラウザ内（IndexedDB / Web Crypto API）に安全に保存・暗号化します。

- **Vercel デモURL**: `https://kakeibo-app.vercel.app` （※Vercelデプロイ後に公開）

## 1. 主な特徴・機能

### 🏠 ホーム画面（第11章 仕様準拠）
- **総資産カウントアップ表示**：登録されている全口座の残高を集計し、滑らかなカウントアップアニメーションで表示。
- **3列収支サマリーカード（11-2）**：
  - 今月の「収入」「支出」「収支（収入 − 支出）」の3つを横並びカードで表示。
  - 収支はプラスなら「+」、マイナスなら「−」の記号および色で明瞭に区別。残高調整は除外。
  - 375px幅モバイル表示でも金額を省略せず、可変フォントサイズ（`clamp()`）で美しく収まるレイアウト。
- **アプリ内通知ボタン**：
  - ヘッダー右上にベルアイコンの通知ボタンを配置。未読件数をリアルタイムバッジ表示（0件非表示、1〜99件は数字、100件以上は「99+」）。
  - アクセシビリティに配慮した44×44px以上のタップ領域と `aria-label`。
- **支出内訳ドーナツグラフ**：Recharts による視認性の高いカテゴリ別支出グラフ。

### ⚓️ ドック風タブバー（11-3 React Bits Dock 参考）
- 画面最下部から少し浮かせた角丸・半透明ガラスモーフィズム（`backdrop-filter: blur(16px)`）のフローティングドック。
- **拡大インタラクション**：
  - マウス操作時：カーソルが近づいたアイコンおよびその両隣がなめらかに拡大（近接コサイン減衰計算）。
  - タッチ操作時：タップ中および選択時のバウンド・スケール演出。
  - モーション軽減（`prefers-reduced-motion`）時は拡大アニメーションを安全に無効化。
- **表示とアクセシビリティ**：
  - 「ホーム」「入出金」「家計簿」「口座」の4タブ。アイコンとラベルを常時表示。
  - 選択中タブは塗りアイコン（fill）、強調色、アクティブドットインジケーターで明示。
  - `role="tablist"`, `aria-selected` などのARIA属性とキーボードナビゲーションに対応。
- **FAB配置**：ドックと重ならないよう、ドック右上に専用の固定座標で配置。

### ⚙️ 設定画面（11-4 仕様準拠）
- ルート：`/settings`（ホーム右上の設定アイコンから遷移）。
- **FABの自動非表示**：設定画面およびその配下では収支登録FAB（＋ボタン）を非表示に制御。
- **開発者セクション**：
  - 画面最下部に「開発者」セクションを設置。
  - GitHubへの公式リンクボタンを配置（`target="_blank"`, `rel="noopener noreferrer"`, 「GitHub」ラベル付き、アクセシブルな `aria-label`）。
  - リンク先URLは `src/config/links.ts` で定数管理（`GITHUB_URL`）。
  - アイコンはブランドガイドライン準拠の公式SVGロゴを使用（タップ領域44×44px以上を確保）。

### 📝 入出金画面：カレンダー・検索・絞り込み（11-5 仕様準拠）
- **厳格なレイアウト順序**：「カレンダー → 検索バー → 絞り込み → 履歴一覧」。
- **カレンダー**：
  - 前月・翌月ボタンと年月表示による月切り替え。
  - 各日付マスにその日の収入合計（+ 緑）と支出合計（− 赤）を表示（残高調整は除外、375px幅では「1.2万」等の可読性の高いコンパクト表記、`aria-label` には正確な金額を付与）。
  - 今日の日付を強調表示。
  - 日付タップでその日の取引に絞り込み（再タップまたは解除ボタンで全件表示に復元）。
- **検索バー**：
  - 取引内容（メモ）、分類名、口座名、金額（カンマ有無不問）をリアルタイム検索。
  - 300msのデバウンス処理、クリアボタン（×）付き。
- **絞り込みチップ**：
  - 種別セグメントコントロール（すべて / 支出 / 収入）。
  - 種別に連動した分類チップの横スクロール複数選択。
  - 検索・日付・種別・分類のAND複合条件フィルタリング。
  - 該当件数バッジ表示と「条件をクリア」ボタン。
- **履歴一覧**：登録日時（`createdAt`）の新しい順でソート表示。

### 🔔 アプリ内通知機能（/notifications）
- **通知の仕組み**：アプリ更新時に更新履歴（`src/data/releases.ts`）をもとに通知を追加。OSプッシュ通信を行わず完全端末内（IndexedDB）で既読管理。
- **初回起動時の扱い**：初回開いた端末では過去の更新をすべて既読登録し、不必要な未読バッジの乱発を防止。
- **通知一覧画面（/notifications）**：Gmail受信トレイ風のリスト。未読ドットと太字で視覚・スクリーンリーダー双方に対応。「すべて既読にする」機能付き。
- **通知詳細画面（/notifications/:version）**：更新内容の全文箇条書きを表示。閲覧時に自動で既読化。

### 🎨 デジタル庁デザインシステム・アイコン仕様（第10章・第11章 仕様準拠）
- **公式素材の完全採用**：デジタル庁が配布する「イラストレーション・アイコン素材」SVG（`src/assets/icons/digital-agency/`）を使用。
- **自作SVGの画風統一**：公式素材に存在しないアイコン（鉛筆、ゴミ箱、カレンダー、財布、グラフ、追加、閉じる等）についても、デジタル庁のグリッド（24×24px）、線幅（1.5px）、角丸仕様に厳格に合わせたカスタムSVGを作成して統一（ブランドロゴであるGitHubとXのみ公式ロゴSVGを使用）。
- **インラインSVGコンポーネント化**：`<Icon name="..." variant="line"|"fill" size={24} />` により `currentColor` でテーマ・強制カラーモードと完全連動。
- **線（line）と塗り（fill）の状態連動**：ボトムタブバー等で非選択時＝線、選択時＝塗りを正確に切り替え。
- **アクセシビリティ**：装飾アイコンへの `aria-hidden="true"`、意味を持つアイコンへの `role="img"` / `aria-label`、および44×44px以上の十分なタップ可能領域を徹底。
- **絵文字・チープな汎用アイコンの完全排除**：アプリ全域から絵文字（Unicode emoji）を排除。

### 💳 口座管理
- **複数口座の管理**：現金（財布）、銀行口座、クレジットカード、電子マネー、投資口座などに対応。
- **残高調整機能**：実際の現在残高を入力するだけで、差額を自動計算して「調整取引」として履歴に記録。
- **初期残高設定・カラー/アイコンカスタマイズ**。

### 📝 収支入力・履歴
- **モーダル型収支入力（FAB対応）**：どのタブにいても右下の「＋」ボタンから素早く支出・収入を記録。
- **インタラクティブカレンダー**：日付選択が直感的に行える独自カレンダー。
- **入出金履歴一覧**：作成日時の新しい順にソート表示、編集および即時削除（Undo通知トースト付き）。

### 📊 家計簿レポート
- **月別切り替え**：前月・翌月へのワンタップ移動。
- **支出 / 収入の円グラフ切り替え**：各カテゴリの構成比（%）および金額順ソート一覧。

### 🔒 設定・セキュリティ
- **テーマ切り替え**：ライトモード / ダークモード / システム自動追従。
- **パスコードロック**：
  - Web Crypto API（PBKDF2 100,000回反復 + AES-GCM 256bit）を用いた安全なハッシュ・検証。
  - アプリ起動時の画面ロック認証。
- **データバックアップ・復元**：
  - JSON形式での全データエクスポート / インポート。

## 3. デザイン方針 & 実装

### デジタル庁デザインシステム準拠
- **カラーパレット**：デジタル庁推奨ブルー（`#1a73e8`）を主軸とし、アクセシブルなセマンティックカラー（Success, Warning, Error）を採用。
- **タイポグラフィ**：Noto Sans JP を採用し、フォントサイズ・行間・文字間を規定。
- **コントラスト比**：WCAG 2.1 AA 基準（通常テキスト4.5:1以上、大型テキスト3.0:1以上）をクリア。
- **インタラクション**：すべてのボタン・リンクでタップターゲット44x44px以上を確保。キーボード操作時の明確なフォーカスリング（`--color-border-focus`）を実装。
- **モーション**：`prefers-reduced-motion` を検知し、ユーザーのシステム設定に応じてアニメーションを自動抑制。

### デザイントークン
`src/styles/globals.css` にて、以下のトークンをCSS変数として一元管理しています：
- カラー（ライト / ダークテーマ対応）
- 余白（`--space-1` 〜 `--space-16`、4pxグリッド基準）
- 角丸（`--radius-sm` 〜 `--radius-full`）
- 影（`--shadow-sm` 〜 `--shadow-xl`）
- トランジション（`--transition-fast`, `--transition-base`, `--transition-slow`）
- セーフエリアインセット（`env(safe-area-inset-*)` 対応）

## 4. 前提条件・設計判断事項の記録

開発にあたり、以下の設計判断を行いました：

1. **タイムゾーン・日付の取り扱い**
   - UTC変換による「日付が前日にずれる」問題を防止するため、すべての入出力・保存形式（`YYYY-MM-DD`）を**ローカル時間基準**で処理する設計を採用（`src/utils/date.ts`）。
2. **残高調整のデータモデリング**
   - 口座残高の不整合を手動で直す際、過去の取引を書き換えるのではなく、`kind: 'adjustment'` の独立した取引レコードを作成し、透明性と監査性を確保。
3. **パスコード認証の暗号化方式**
   - パスワード平文や単純なハッシュではなく、W3C標準の Web Crypto API を利用。
   - `PBKDF2`（SHA-256、100,000回ストレッチング、16バイトランダムソルト）による暗号鍵導出と、`AES-GCM`（12バイトIV）による検証を実施。
4. **PWAキャッシュ戦略**
   - オフライン利用を最優先とし、HTML・JS・CSS・Webフォント・アイコンをService Workerで事前キャッシュ（Precache）。
   - データ自体はIndexedDBに保持されるため、完全オフライン環境でも家計簿の入力・閲覧・分析が可能。
5. **アクセシビリティ対応**
   - モーダルやダイアログに `role="dialog"` / `role="alertdialog"`、`aria-modal="true"`、フォーカストラップ対応。
   - カレンダーやセグメントコントロールへの適切なキーボード・スクリーンリーダー属性の付与。
6. **ホーム収支サマリーカードの375px幅レスポンシブ表現（11-2）**
   - 375px幅で「収入」「支出」「収支」の3つが横並びになった際、数字の省略表示（1.2万等）を避け、CSSの `clamp(0.85rem, 3.2vw, 1.15rem)` による動的フォントサイズ調整を採用。
7. **Dock風タブバーとFABのレイアウト配置（11-3）**
   - React Bitsの Dock コンポーネントに倣い、マウス近接時のコサイン減衰拡大演出とタッチ時バウンドを実装。
   - フローティングDockの高さ（約64px + 下余白12px + safe-area）と重ならないよう、FABの配置位置を `bottom: calc(var(--safe-area-bottom, 0px) + 88px)` に調整。
8. **設定画面でのFAB制御と公式ブランドロゴ（11-4）**
   - 11-4の指示に基づき、`/settings` 配下でFABを非表示化。
   - GitHubの公式ロゴはブランドガイドライン準拠の公式SVGを採用し、デジタル庁デザインシステムのタップ可能領域（44×44px）を維持しつつ安全な外部リンクを構築。
9. **入出金カレンダーと検索・絞り込みのAND合成（11-5）**
   - カレンダー上の日別集計は絞り込み状態に関わらずその日の全取引（残高調整除く）を対象とする要件を満たすため、カレンダーデータ用と履歴リスト用の集計処理を分離。
   - 履歴リスト側は「検索（メモ・分類名・口座名・金額カンマ有無）」「日付（カレンダー選択）」「種別（セグメント）」「分類（複数チップ）」をAND合成して瞬時に絞り込む純粋関数 `filterTransactions` として実装・テスト。
